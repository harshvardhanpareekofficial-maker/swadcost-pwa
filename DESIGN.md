# Loomroom — complete visual redesign
User rejected the previous inherited plum/paper UI. This direction replaces its composition, type, palette and graphic language.
Audience: mill owners preparing accurate grey-fabric quotes. Primary action: build a costing sheet.
Palette: loom indigo #2436a8, midnight #15214b, cloud #f2f5fc, white #ffffff, shuttle orange #ff7849, slate #64718b.
Typography: Space Grotesk for display and numbers, Manrope for readable controls. Local system sans fallback.
Layout: full-width top navigation; open centered workspace, two-column construction selection, paired input panels. Mobile collapses to a single column. Login uses a full-height indigo illustration panel beside the sign-in workspace.
Signature: a custom vector textile swatch built from crossing ribbons, with cloth-edge notation. No stock or generated imagery needed.
Critique: removed the generic decorative sidebar and old gradient paper cards. Textile structure carries the visual identity. Orange is reserved for small markers and actions; fields stay quiet.
Preserve the calculation engine, input units, authentication behavior, owner gate and private URL. UI work does not modify rounding.
