# Website redesign acceptance — 2026-10-23

User priority: remove filler, use only the superdynamic preset, and fit each screen without ordinary page scrolling. Follow-up: replace the ominous camera with a softer model.

## Changed behavior

Short product chooser with interactive real GLB objects; compact tabbed desktop downloads; reduced sign-in copy; paged numeric forms, results, guides and protected owner lists. Rounded ivory camera, small blue lens, neutral lighting, manual rotation/reset/pause and static fallback. Existing formulas, file targets and authentication functions retained.

- Initial 298-test run: 293 passed, five tests failed because they required removed marketing copy/sections. Updated those presentation assertions to the requested concise UI; retained authentication, formula and privacy assertions.
- Test discovery originally included only .test.ts; extended it to .test.{ts,tsx}. Final actual run: **301 tests passed, zero failed**, including three new DOM tests for all 13 single and 29 multi fields, persistence across paging, and complete print output.
- Production build passes. Existing >500KB chunk advisory remains (app/vendor and lazy Three loader). Camera GLB is 649,980 bytes. No runtime/model packages were rebuilt by this website task.
- Browser checks at 1440×900, 390×844 and 365×640: homepage, desktop download tabs, sign-in/create-account, help, construction, entry-method, all input pages and result sections. Measured scrollHeight equal to viewport height on tested phone screens; fields remain above navigation.
- Real page components tested in a local synthetic fixture without account creation or telemetry. Single sample result: **INR59.40**. All multi fields reached. Existing single-equivalent multi sample also INR59.40.
- Camera rotation, reset and pause operate. Reduced-motion emulation disables ambient playback. Blocking the camera GLB leaves the SVG poster and working download navigation. Overrides restored after testing.
- Existing cloth variant selection changes pressed state and loads the real cloth controls.
- Every results page is retained in the print-only report. Formula and stored data functions remain unchanged.
- `qa/screen-preview.html` and its TSX fixture are not production build entries; verified `dist/qa` absent.
- No new live accounts, payments, uploads of private files, or private owner-record inspection.

## Limits

The 480px-height accessibility fallback allows scrolling when a keyboard, zoom or short landscape window needs it. Factory host, phones, model accuracy and native packages are separate acceptance work. A finished site layout does not establish those capabilities. Private ledger authentication is covered by existing tests; no claim of a fresh live owner sign-in.
