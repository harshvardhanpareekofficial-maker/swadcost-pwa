# fabriccost STUDIO — September 25 release

Based on the existing Render deployment and repository commit 8ec6a57. Existing user sign-in storage keys and database tables are preserved.

## Formula contract

The calculation engine `src/lib/costing.ts` is unchanged. Warp: RS × reed × 120 / (1825 × count × L2L). Weft: RS × pick / (1693.33 × count), then wastage on weft only. Sizing uses warp weight; majuri is paise per pick, divided by 100. Flat warping is added once.

Weights round to six decimal places, component costs to four, totals to two. Single mode totals unrounded components; multi mode sums the four-decimal yarn components. Markups use the rounded two-decimal total. This intentionally preserves the live PWA rather than changing its rounding model.

120 golden test cases were captured from the live JavaScript asset and compared against every output field. These are equivalence tests, not a claim that the owner's notebook formula is interchangeable with every industry costing method. Browser samples: 50-paise sample = 59.40; 12-paise sample = 33.56 and making charge 8.16.

## Website and PWA

Wider desktop warp/weft layout, compact mobile screens, installation controls, print / PDF, and preserved Type / Speak choice. Microphone starts only on request. Browser speech requires a supported browser and network service; physical microphone accuracy requires the user's own environment.

New calculations store their full input payload. Offline records queue on the device and retry on reconnect with a stable UUID. Historical records retain exactly what the previous version recorded; missing historical yarn rates are not invented. Clearing browser data before sync loses pending records.

## Owner ledger

Separate unlinked route. A newly generated password is checked by the Edge Function; only its SHA-256 digest appears in server source. The password is held only in memory while unlocked, expires after 15 minutes, and is never stored in browser storage or the public bundle. The endpoint limits requests, returns no-store responses, and pages through all records. Anonymous direct table reads/writes are revoked at production cutover. CSV exports escape formula-leading text. Date/search filters and an explicit verification-entry filter control all rankings.

User accounts remain the prior device-local password system, including its cross-device setup behavior. Gateway activity/record endpoints collect unverified client telemetry; a user ID is not a cryptographically verified identity. This release secures owner-only reads; it does not claim to migrate every user to Supabase Auth. Server-side automatic idle deletion is disabled to preserve the ledger; existing local sign-in expiry is retained.

## Android

Capacitor Android package: com.harshvardhanpareek.fabriccost. Android 7+ (API 24), bundled web assets, no remote-code URL. Separate release signing key, native Android print bridge, app-specific woven icon, Android backup disabled. APK signature verification is required. Keep the private signing backup to sign future updates. Native WebView speech availability differs from Chrome; Type and keyboard dictation remain available.

## Operations

Render builds from the main branch using existing public Supabase URL/anon-key environment variables. No owner password belongs in VITE variables. `supabase/functions/fabriccost-gateway/index.ts` contains the server password digest. Rotate by generating a new long random password and redeploying the digest; deliver the plaintext privately.

Unit tests block all real network traffic. Run `npm test`, `npm run build`, `npm run lint`, `npm audit`. Build Android with `npx cap sync android` then `android/gradlew -p android assembleRelease`; align and sign externally. Never commit a signing keystore or password.
